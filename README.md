# Персональный сайт-портфолио

Современный персональный сайт-визитка с тёмной темой и анимациями.

## 🚀 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современный дизайн с CSS-переменными
- **JavaScript** - интерактивность и анимации
- **Google Fonts (Inter)** - типографика

## 📁 Структура проекта

```
razetka2010.github.io-main/

├── profession.html         # Страница "Моя профессия"
```

## 🎯 Особенности

### Анимации
- `pulse` - пульсация фона hero-секции
- `float` - движение частиц
- `glow` - свечение вокруг аватара
- `shimmer` - мерцание подчеркиваний заголовков
- `gradient-shift` - анимация градиента
- `fadeIn` - плавное появление секций

## 🛠️ Установка и запуск

### Локальный сервер (рекомендуется)

```bash
# С помощью Node.js
npx serve -s -l 8000

# Или Python 3
python -m http.server 8000
```

Откройте браузер: http://localhost:8000

### Прямое открытие
Просто откройте `index.html` в браузере (некоторые функции могут быть ограничены из-за политики безопасности file://)

## 🔧 Кастомизация

### Изменение цветов
Отредактируйте CSS-переменные в `:root`:
```css
:root {
    --color-accent-primary: #f59e0b;  /* Основной акцент */
    --color-accent-secondary: #10b981; /* Вторичный акцент */
}
```

### Добавление секций
1. Создайте HTML-разметку в `index.html`
2. Добавьте стили в `css/style.css`
3. Следуйте существующей структуре секций
